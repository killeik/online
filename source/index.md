# Hello, friend!

Website is under development, so it's fine if you meet some 404 skeletons :p

## What this place is about

- This website is manifestation of what I actually like
- I plan to gradually expand the lists in each category.
For example, adding links to beautiful websites, useful tools, etc.
- This page is a guideline for writing a website.

## About website content

- [Hypertextual maximalism](https://libre.town/thoughts/entry_9.xhtml)
- [ASCII](https://ascii.co.uk/art) [art](https://www.asciiart.eu/image-to-ascii) is [beautiful](http://patorjk.com/software/taag/)!
- And the boring part is to break free of mental barriers:
This website is my subjective position and does not claim to be the objective truth.
I will try to express my position honestly and without a huge disclaimer before each article.
My position changes. The expression of my position on the site is probably outdated by now.

## Technologies

Mixed Markdown and [semantic HTML](https://www.w3.org/WAI/WCAG21/Techniques/html/H101), basic CSS, as little JS as posible.

- Editing in [nvim](https://neovim.io/)
- Code repository on [GitHub](https://github.com/killeik/online)
- Rendering from templates/markdown with [Eleventy](https://www.11ty.dev/)
- Hosting on Cloudflare Pages
